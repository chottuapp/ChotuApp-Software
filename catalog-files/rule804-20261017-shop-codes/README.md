# Rule 804 results with shop codes

13 completed online-fetch store workbooks; 12,886 products. Source: published Rule 804 results at ec2c9c2. These are not older unprocessed exports.

One text column, `shop_code`, was appended to the Products sheet. Every product in each workbook has that store’s exact code from the supplied shops CSV. The user explicitly confirmed that CSV shop “Hunger” (SE10007) means The Hanger Pakistan. Elite Cosmetics uses SH10003, exactly as supplied.

All previous cell values, original cell XML, product order, formulas, hyperlinks and other workbook ZIP parts are preserved. Variant and image sheets are unchanged. Category-wise cheaper-first ordering and the earlier Rule 804 edits are retained. The importer must read Products.shop_code and validate it against the selected shop; adding a column does not automatically update website code.

The blank template includes shop_code as an empty column. Supply the same correct code for every product in a new single-store workbook.

The original shops CSV is not included: unrelated shop records, contact details, payment fields and tokens are not published. Only these 13 required shop name/code mappings are included.

The source workbooks have review notes and upstream limitations documented in the preceding Rule 804 package; adding shop codes does not resolve those source issues.
