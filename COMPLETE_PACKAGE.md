Complete ChotuApp source bundle — 2026-10-14

This ZIP combines the current R11 extraction engine with discounted top-20 ordering, discount tags/importer aliases, 0.35-second adaptive baseline pacing, saved runs, UI responsiveness support, optional daily automation/Windows login startup, and two-worker Controlled Fast Fetch with shared adaptive throttling. No separate patch installers are needed for this ZIP's main.py.

Files: main.py is the integrated application, resume_support.py, automation_support.py and fast_fetch_support.py are required support modules, requirements.txt lists existing pinned dependencies, and both XLSX files are blank discount-tags templates. No private store lists, logs, exported catalogs or saved checkpoints are included.

For Google AI Studio/developers: keep these files together and start by reading main.py plus all three support modules. Preserve current extraction logic unless explicitly requested. Match each selected combination against Variant Combinations; use its sale price when present, otherwise its base price, availability, and variant_image_url. Do not substitute the product's cheapest price for a selected bundle. Preserve unavailable variants as no and exclude whole unavailable products and explicit Free Gift promotions. Keep every product image with website cover first. Descriptions are source-grounded; retain applicable detailed specifications. Best-selling discounted order must be supported by verified storefront ranking. Percentage tags are calculated from prices; source_discount_tag remains blank unless independently fetched/verified.

Compatibility: Products includes legacy fields and importer aliases/gallery_urls. Variant Combinations includes exact dimension values, source variant ID, base/sale prices, availability, image, and discount columns. This desktop software generates XLSX; it does not implement the ChotuApp backend importer or storefront variant selection behavior.

To install over an existing Windows app: close it, extract ZIP to a separate folder, open CMD there, run `py install_complete_update.py`. It backs up and replaces program files, preserving existing settings, user templates, exports, checkpoints and store lists. Restart `py "%USERPROFILE%\Desktop\ChotuApp_Software\main.py"`. Select the Discount_Tags template via Browse file for new exports; Continue uses its saved template snapshot. Dependencies are not reinstalled automatically; for a clean installation run `py -m pip install -r requirements.txt` if needed.

For a separate development copy: install requirements, then `py main.py`. Source uses the existing Desktop data paths, so use an isolated account or explicit local path overrides when testing. Regression tests are in the GitHub repository tests/ directory, not in this source ZIP; they use temporary paths and fixture data. Linux GUI tests need a virtual display; Windows touchpad and Windows login startup require hardware verification.

Daily automation is disabled in a fresh installation; existing enabled settings remain. See DAILY_AUTOMATION.md. Same-day interrupted runs reuse their saved snapshot; new daily runs fetch fresh. The laptop must be awake, logged in and online. Public-site rate limits can still slow requests; no guaranteed completion time or perfect-current-price claim is made.
