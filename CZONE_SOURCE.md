# Czone Webx support

Close ChotuApp before running install_czone_source.py --with-browser. The installer adds a Czone-only hook and module, and backs up the existing program. It does not replace the extraction engine, templates, stores, exports or saved runs. Only the Playwright Python package is installed if missing. Public catalog discovery uses existing Google Chrome, then Microsoft Edge, then an already available Playwright Chromium. No browser download is attempted; every browser uses a separate temporary profile.

Use the clean store URL https://www.czone.com.pk/ and select Computer Zone only, then New Fresh Run. Continue Saved Run reuses that interrupted run's successful public HTTP responses through the existing cache; New Fresh Run gets a new checkpoint. Chromium catalog discovery itself repeats on continuation when needed. No user browser profile is used.

Product sources were verified against two user-supplied public Webx page snapshots: Rs. 250 adapter with two images and six-month warranty; Rs. 500 cable with seven-day checking warranty. Both parse with exact rupee prices, SKU, brand, source URL, categories, highlights and gallery. No division by 100 is applied. Displayed product price, JSON-LD offer and Webx product state must agree. Used-condition offers remain used. Order-only and out-of-stock products are excluded.

The sitemap snapshot contained fewer candidates than the public catalog's 1,876 products. The browser fallback follows the real loading UI, rather than guessing an API URL or declaring the first 12 items complete. Export requires the final verified unique-product count to equal the public count. A change during fetching, missing item or blocked request stops publication and retains existing exports and saved responses. Unexpected variants or unavailable technical specifications also stop rather than silently dropping required details. This conservative adapter is not universal Webx variant support.

Descriptions include supplied description, highlights, scoped technical information and warranty text. Technical ingredient/specification values are not invented. Source-reported soldQuantity controls popularity ordering within discounted/non-discounted groups; this is not independently verified sales. Discount prices use the product's current price and larger list price, with template tags generated by the existing writer.

The adapter stages its workbook through the existing export wrapper, preserving prior FINAL files, and marks output REVIEW REQUIRED. It does not claim browser rendering, stock, importing or all 1,876 live products have been tested here: network access to Czone is blocked in this environment. Ten automated checks cover product identity, price disagreement, rupee units, gallery/warranty, out-of-stock state, discounts, unknown variants, install-hook preservation, non-Czone dispatch and workbook export. Two actual captured product pages were additionally parsed locally. Windows browser/catalog integration must be observed on the user's machine.

## Parallel fetch update

Czone now uses three bounded HTTP workers, each with its own session and SQLite cache connection. All workers share the existing source request gate; a recent throttling recovery hold retains one worker. No other store worker count or pacing is changed. Successfully fetched pages are committed to the existing per-run cache and reused on continuation. A failed source check stops scheduling additional work; already active requests finish and retain their successful responses. Stock is checked before variant interpretation: On Order Only and out-of-stock products count toward catalog completeness but are not exported. In-stock unknown variant schemas still stop rather than guess stock or prices.

Tests additionally verify concurrent overlap is bounded at three, cached responses are reused without network calls, the parent thread retains its source gate, and order-only products with variants do not invoke unsupported variant interpretation.
