# Description software release — 6 November 2026

The owner requested substantially better English descriptions and permitted restrained emojis/boxes. The shared software now renders source-bound customer copy with relevant Unicode headings and bullets. [Real before/after examples](description-upgrade-20261106.md).

Fresh fetching, the desktop installers/bundle and the saved-workbook Rule 804 pipeline use the same renderer. It retains sourced materials, ingredients, measurements, directions, precautions, warranty and exact option values. It removes known sales padding and generic category sentences. Missing specifications and benefits are never invented. Concise explicit material/design/pack facts are valid regardless of word count. This is deterministic source-based editing, not a separate generative AI service or human review.

The audit checks substantive content apart from name/code/options. Genuinely incomplete products and linked rows are excluded under the owner's existing policy; price, stock, identity and conflicting-fact errors remain blocking. Original inputs remain durable and unchanged. Every excluded identity/reason is archived in a separate receipt. Public summaries are bounded to 100 entries without limiting the all-row audit. Over-capacity descriptions are quarantined instead of silently truncated, including during initial source extraction.

Targeted reprocessing of a previously passed input requires the exact source run and SHA of the current verified Drive receipt. It cannot replace a newer source with an older workbook. Delivery stages and checksum-verifies replacements before promotion. No additional fresh fetches or cloud environment setting changes were started for this description release.
