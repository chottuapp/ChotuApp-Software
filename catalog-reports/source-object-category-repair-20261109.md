# Source object category repair

Public Blackbeiger product/collection inspection run 42655041820 confirmed 184 exact source product IDs in footwear collections. BALLET COAT - WHITE/CHERRY belong to Flats and Pumps; CAMILA belongs to Heels. Styling prose about wearing heels with straight pants and the phrase black foundation in a khussa description had been incorrectly used as clothing/cosmetics evidence.

A shared source-object classifier now prioritizes explicit merchant product types and verified category paths. It identifies primary footwear without treating styling suggestions or shipping/refund copy as sold objects, preserves source descriptions, and holds the ambiguous BALLET COAT name unless actual category evidence resolves it. Product type metadata is exported for future reprocessing. Existing Blackbeiger records are bound to exact public title, source URL and product ID, with actual collection URLs and memberships retained. This is reusable logic and source evidence rather than manual Excel edits.

The independent audit separately rejects footwear assigned to trousers, dresses, coats, cosmetics or jewellery; it checks actual source collection evidence without calling the classifier for approval. Manual owner categories, grocery scope, price/stock/variant/image facts and source evidence are preserved. Runtime packaging and fetch/delivery preflights include the new shared module and regressions.

Mansab public Supabase JPEGs returned HTTP 200 under normal and Dart mobile User-Agent requests. The customer/rider/admin URL resolvers lacked a generic foreign-host guard, allowing external /storage/ URLs to be rewritten to the Chotu API host. An isolated private-repository change preserves external media hosts/paths/signatures while retaining local variant resolution; no private source is placed in this public repository. Targeted tests cover each client. Existing mobile installations require the tested app fix to be released; source photos do not require fabricated replacement URLs.

The first saved-input audit inspected 208 products and held five LACE-named shoe designs because an accessory exclusion was too broad. Require explicit shoe/replacement-lace wording before excluding laces as accessories, so exact website Flats evidence remains authoritative for BELLE LACE/LACE shoe designs. This edge case has a regression test. Source evidence checked time is the successful inspection workflow completion timestamp, not a guessed timestamp.
