# Rule LAAM

User-approved scope, 20 October 2026. Applies only to LAAM, independently of Rule 804 and other stores.

Include clothing: stitched suits, unstitched suits/fabric clothing products, readymade/ready-to-wear garments and other clothing. Do not restrict clothing to stitched products or suits alone.

Exclude bags, jewellery, footwear, cosmetics and other non-clothing products. Use the source's Clothing category (node_l2), with the explicitly labelled description Category as a fallback when node_l2 is absent. Product title keywords alone do not establish clothing. Unclassified products are excluded with a log entry rather than guessed.

Preserve verified product prices, stock, variants, descriptions and image URLs for included clothing. Product-page discovery totals are not counts of qualifying exported clothing. The clothing filter applies when running the updated LAAM adapter; already running processes retain their loaded code until a saved-checkpoint resume with the update.
