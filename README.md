# ChotuApp cloud diagnostics

Automatic structured reports only; application code remains on main.
Reports include store names, outcomes, product counts, HTTP/timing/cache metrics and source revision. No raw logs, response bodies, credentials, cookies, Excel files or response databases are committed here.

The assistant does not receive background notifications. Ask it to check this branch when diagnosing a run. Full redacted logs remain in the short-lived diagnostics artifact.
